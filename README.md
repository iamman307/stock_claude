# Stock Claude 投資總帳

本機優先（local-first）的個人投資總帳 PWA：美股／台股、幣安、證券交割戶對帳與績效分析。可以安裝到手機主畫面，離線開啟。

## 和舊版 Wealth Ledger 的差異

| 項目 | 新版做法 |
|---|---|
| 資料保護 | 讀取失敗時**絕不覆蓋**原始資料，進入救援模式並暫停儲存；每次修改前自動保留前一版（最多 15 版），可一鍵還原 |
| 交割戶 | 餘額 = 上次核對的銀行快照 ＋ 之後的交割與轉帳。核對時直接顯示差額，不再用手動「現金校正」補帳 |
| 幣安 | 損益 = 最新總資產 − **快照當時以前**的淨投入。快照之後才轉入的錢不會被誤算成虧損 |
| 匯率 | 自動抓 USD/TWD 參考匯率並提醒過期；未實現損益拆成「股價變動」與「匯率變動」 |
| 整批交割 | 只需輸入一次銀行淨額，反算共同匯率。淨額太小（低於 300 美元）時改填成交匯率，避免四捨五入放大誤差；反算匯率偏離參考值超過 2% 會警告 |
| 績效 | 波段：完整平倉才算一筆樣本，勝負與比率一律以台幣損益判斷。長期：資金加權報酬（滿 90 天才顯示年化 XIRR） |
| 時間 | 所有時間一律以台北時間（+08:00）儲存，換裝置或出國也不會亂序 |

## 使用

1. 打開網頁 → 「匯入備份檔」，選擇舊版 Wealth Ledger 匯出的 JSON。匯入前會列出所有轉換假設。
2. 到「資金」頁按「核對餘額」，輸入目前交割戶的銀行餘額。
3. 到「資金」頁按「更新總資產」，輸入幣安目前的台幣估值。
4. 之後每天打開會自動更新匯率，並記錄一筆總資產，累積成資產走勢。

美股報價需要免費的 [Finnhub](https://finnhub.io) API 金鑰（設定頁）。台股請用手動報價。

## 隱私

- 公開儲存庫只有程式碼。交易、持倉、貸款與資產資料只存在瀏覽器的 `localStorage`，不會上傳。
- `.gitignore` 排除所有 `.json`（manifest 與 package.json 除外），避免不小心把備份檔 commit 上來。
- Finnhub 金鑰只存在當前裝置，不會寫進備份檔；查詢時放在 HTTP header，不出現在網址裡。
- 換手機或清除瀏覽器資料前，請先到設定頁「匯出備份」。

## 開發

純 HTML／CSS／JavaScript，不需要打包工具。

```bash
npm test          # 執行單元測試（Node 20 以上）
npm start         # 本機預覽 http://localhost:8080
```

| 檔案 | 用途 |
|---|---|
| `js/core.js` | 計算引擎（純函式）：持倉、損益、交割、對帳、績效、提醒 |
| `js/migrate.js` | 舊版備份轉換 |
| `js/storage.js` | 本機儲存、版本紀錄、救援模式 |
| `js/market.js` | 匯率與報價 |
| `js/charts.js` | SVG 圖表 |
| `js/app.js` | 介面 |

推送到 `main` 後，GitHub Actions 會先跑測試，通過才部署到 GitHub Pages。第一次使用請到 **Settings → Pages → Source** 選擇 **GitHub Actions**。
